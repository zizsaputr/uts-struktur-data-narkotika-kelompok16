# CONTRIBUTIONS

## Project Overview

**Nama Proyek:** Sistem Pengelolaan Putusan Pengadilan Narkotika

**Repository:** https://github.com/zizsaputr/uts-struktur-data-narkotika-kelompok16

Struktur Data yang Digunakan

Program ini menggunakan dua struktur data utama dalam pengelolaan data:

Singly Linked List sebagai struktur data utama untuk menyimpan, menampilkan, menambahkan, menghapus, mencari, dan mengelola data putusan pengadilan.

Stack sebagai struktur data sekunder untuk menyimpan riwayat aktivitas dengan prinsip LIFO (Last In, First Out), yaitu data yang terakhir dimasukkan akan menjadi data pertama yang dikeluarkan.

Kedua struktur data tersebut diimplementasikan untuk mendukung pengelolaan data putusan dan pencatatan aktivitas aplikasi.
